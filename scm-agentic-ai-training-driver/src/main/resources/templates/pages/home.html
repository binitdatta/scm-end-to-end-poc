What this POC proves

Agentic AI should orchestrate enterprise capabilities — not replace them

The model reasons and plans. The deterministic systems still own transactions, data, authorization, lifecycle rules and operational truth.

Reason

Anthropic interprets the goal and helps produce a constrained multi-step plan.

Orchestrate

LangGraph carries explicit state through tool execution, validation, approval and recovery paths.

Execute

Approved tools invoke Spring Boot APIs that own CRM, vendor, procurement, WMS, OMS and TMS functions.

Govern

HITL gates, audit trails, policies and service boundaries contain the agent’s autonomy.

Course thesis

A serious enterprise agent is a distributed system with an LLM inside it.

The course uses the POC to explain the architecture around the model: APIs, state, bounded contexts, data ownership, eventing, security, HITL, failure recovery, observability and responsible autonomy.
