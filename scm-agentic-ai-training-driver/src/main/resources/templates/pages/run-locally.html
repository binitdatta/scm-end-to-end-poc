Hands-On Setup Guide

Run the Complete SCM Agentic AI POC on Your Laptop

This guide walks through the complete local setup of the End-to-End Supply Chain Agentic AI Proof of Concept on either macOS or Windows.

You will install the required development tools, clone the GitHub repository, create the MySQL schemas and seed data, build and run seven independent Spring Boot REST APIs, launch the Spring Boot ERP dashboard, and finally configure and start the Python / LangGraph Agent Control Tower.

Spring Boot Backend

Open the Seven Business Services in IntelliJ IDEA

Each service is an independently running Spring Boot application exposing its own REST API.

# Application Business Domain URL
01 cs-crm-api CRM / Campaign localhost:8081
02 cs-vendor-api Vendor / RFQ localhost:8082
03 cs-procurement-api Procurement / Purchase Orders localhost:8083
04 cs-wms-inbound-api Warehouse Inbound localhost:8084

07 cs-tms-api Transportation Management localhost:8087
IntelliJ setup

Open each application directory as a Maven project. IntelliJ should detect the pom.xml and configure the project using JDK 21.

05
Database Initialization

Create the MySQL Schemas and Seed Data

The transactional services use independent MySQL schemas. Create the database structures before starting the APIs.

1

Locate the SQL

Inside the appropriate project, locate the db directory under the project root.

2

Open the DDL

Identify the schema / DDL .sql file.

3

Run in Workbench

Connect MySQL Workbench to your local MySQL 8 instance and execute the DDL.

4

Load Seed Data

Execute the seed data SQL after the schema has been created successfully.

Database-per-service architecture

Each backend service owns its schema. Do not consolidate the schemas into one shared application database simply for convenience—the separation is intentional and part of the POC architecture.

06
Build

Build Each Spring Boot Application

Maven 
mvn clean install

Maven compiles the application, runs its tests and creates the executable Spring Boot JAR under the project's target directory.

07
Runtime

Start the Spring Boot Services

Java 
java -jar target/<file-name>.jar
Multiple applications require multiple terminals

Keep each Spring Boot service running in its own terminal tab/window, or run them directly through separate IntelliJ run configurations.

09
Agentic AI Runtime

Configure the Python Agent Control Tower

The Agent Control Tower is the Python application that accepts the human business goal, invokes Anthropic for planning and uses LangGraph to orchestrate the backend Spring Boot services.

Python / LangGraph

cs-agent-control-tower

Open this project in PyCharm using Python 3.12.

View Source
Agent UI :9000
1

Open the Project in PyCharm 

cd cs-agent-control-tower
2

Create a Python 3.12 Virtual Environment 

python3.12 -m venv .venv

source .venv/bin/activate
py -3.12 -m venv .venv

.venv\Scripts\activate
3

Install the Python Dependencies 

python -m pip install --upgrade pip

pip install -r requirements.txt
4

Create an Anthropic API Key

Sign in to the Anthropic Console and create an API key for the POC.

Treat the API key as a secret

Never commit the API key to GitHub and never place it directly inside Python source code.

5

Create the Local .env File

Copy the example environment file included in the project. 

cp .env.example .env
copy .env.example .env

Open .env and add the Anthropic API key together with any other environment-specific values documented in the example file.

.env 
ANTHROPIC_API_KEY=<YOUR_ANTHROPIC_API_KEY>
6

Start the Agent Control Tower 

python app.py
http://127.0.0.1:9000
Recommended Startup Sequence

Start the Platform Bottom-Up

Following this sequence makes troubleshooting much easier.

1 MySQL 8 Ensure database service is running
2 Spring APIs Start ports 8081–8087
3 ERP Dashboard Start port 8090
4 Agent Control Tower Start port 9000
